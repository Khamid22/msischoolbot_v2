# Frontend API Route Cleanup Report

Date: 2026-07-07

Scope: frontend route helper cleanup for migrated AD/HOD Teacher Academy actions.

## Route Helpers Added

Created `frontend/src/shared/api/routes.ts` with canonical API v1 helpers for:

- AD HOD creation
- AD Academy Teacher creation
- AD schedule, assess, status, promote, delete actions
- HOD schedule, assess, status actions

## Existing Route Helper Updated

`frontend/src/shared/lib/routes.ts` now imports `apiRoutes` and exposes the same existing route keys through the new `/api/v1` values. This keeps component call sites stable while removing hardcoded role-local action URLs from the main route map.

## Hardcoded URLs Removed

Removed active source references to:

- `/academic-director/api/...`
- `/head-of-department/api/...`
- `/admin/teacher-academy...` action helpers

Remaining old-route strings are negative tests, historical reports, or pre-build generated static chunks that will be regenerated by the frontend build.

## Old Frontend API References Kept

`/admin/api`, `/teacher/api`, and student/general `/api` helpers remain where active UI flows still use them. They should move only with dedicated API v1 replacements and role regression tests.
